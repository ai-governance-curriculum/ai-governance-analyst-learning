# mod-102-ai-system-inventory-and-intake: AI System Intake and Inventory Maintenance

> Scaffolded by `aicg org execute-plan`. Lecture chapters and exercise content are authored on subsequent autonomous cycles.

**Estimated effort:** 12 hours

## Learning objectives

- Design an AI use-case intake questionnaire with the fields employers actually populate: system name, business owner, purpose statement, decisioning autonomy, data sources, model family, deployment surface, integration surfaces, third-party dependencies, EU AI Act tier, applicable sector regulator
- Classify an incoming use case into an in-scope / out-of-scope / needs-follow-up bucket against the enterprise risk tiering, mapping to the EU AI Act tiers plus any internal augmentation
- Build and maintain a model / AI-system inventory row and keep it in sync with the ML team's model registry through a lightweight integration
- Use vendor GRC-for-AI platforms (Credo AI, Holistic AI, ModelOp, ServiceNow AI Control Tower) at an analyst level, and produce the spreadsheet-shaped equivalent when the enterprise has not yet adopted a platform
- Read and summarise pandas / Excel data enough to reconcile a model registry export against a governance inventory and file the delta

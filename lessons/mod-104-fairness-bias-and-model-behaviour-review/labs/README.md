# Labs for mod-104-fairness-bias-and-model-behaviour-review (Reading Fairness, Bias, and Model-Behaviour Reports)

Guided, step-by-step hands-on sessions. Labs complement the module's exercises — the exercises each exercise *one* chapter's mechanics on a batch of inputs; the labs chain *multiple* chapters through a single fixed artefact or drill a single discipline across multiple perturbations. All labs are code-free — no Python or notebook environment is required.

| # | Lab | Focus | Duration |
|---|---|---|---|
| 01 | [One Fixed Bias Report, Walked Through All Four Chapters](lab-01-one-bias-report-four-chapters.md) | Integration drill — one pre-written Fairlearn-style bias report on a résumé-triage system, chained through chapter 01 metric-glossary slice → chapter 02 five-thing reading pass → chapter 03 WIT follow-up plan → chapter 04 Title VII / LL 144 / EU AI Act overlay → remediation ticket and five-question non-technical summary, with cross-section consistency enforced | 2 h |
| 02 | [Report-Stripping Drill on a Fixed Fairlearn Report](lab-02-report-stripping-drill.md) | Reading-discipline drill — one fixed loan-signal Fairlearn report, four distinct stripping scenarios (base rates; confidence intervals; intersectional breakdown; per-group confusion matrices), five-thing pass and five-question summary recomputed each time, highest-impact-omission verdict anchored on the enterprise's register metric | 90 min |

# Labs for mod-103-risk-assessment-authoring (First-Draft AI Risk Assessment Authoring)

Guided, step-by-step hands-on sessions. Labs complement the module's exercises — the exercises each exercise *one* chapter's mechanics on a batch of inputs; the labs chain *multiple* chapters through a single fixed artefact or drill a single discipline across multiple perturbations.

| # | Lab | Focus | Duration |
|---|---|---|---|
| 01 | [One MAP 5 Impact, Walked Through All Five Chapters](lab-01-one-impact-five-chapters.md) | Integration drill — one pre-written MAP 5 impact chained through chapter 01 framing → chapter 02 two-lens overlay → chapter 03 scoring → chapter 04 SR 11-7 overlay → chapter 05 routing packet and executive mention, with cross-section consistency enforced | 2 h |
| 02 | [Control-Defeated Scenario Drill on a Fixed Scored Entry](lab-02-control-defeated-scenario-drill.md) | Scoring-discipline drill — one fixed scored entry (MCDA Data-leakage), four distinct control-failure scenarios, three columns recomputed each time, load-bearing control named by ID, boundary-condition executive mention | 90 min |
